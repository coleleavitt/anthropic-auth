## Fixes

- **Vault mode on Windows: fewer lock errors.** A process reading a vault lock file while another process was releasing or rewriting it could fail with a Windows sharing error (for example `claustrum-roster-write.lock (io-error)`). It now retries within the normal lock wait. (`@cortexkit/common-auth` 0.33.0)

## Changes

- **Shared routing reports (CortexKit agent runner only).** A used-up limit is now reported to shared routing as the five-hour or weekly window, with a model's own limit named as a pool (for example Fable), matching the other auth plugins. Without the runner, nothing changes.

To upgrade, quit OpenCode and Pi and run `npx @cortexkit/opencode-anthropic-auth setup`, or change the version in your OpenCode config.
