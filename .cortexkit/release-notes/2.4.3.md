## Fixes

- **OpenCode 2 cache keep-warm reads the session's cache again.** A keep-warm request sent the stored request through the request rewrite a second time. That renamed every tool again and added the system blocks again, so each idle hour cost two full prompt-cache writes instead of none. Keep-warm now sends the session's request exactly as it was first sent. (#547)
- **Keep-warm keeps more sessions, and says when it drops one.** The memory budget for kept-warm sessions rises from 16 MiB to 64 MiB, measured in bytes. When the budget is full, keep-warm now spares a session about to be warmed, and logs a warning with the reason whenever it stops warming a session whose cache is still alive. (#544)
- **OpenCode 2 and Pi apply the saved log level when they start.** Before, the level picked in `/claude` → Logging only took effect after picking it again in that session. `OPENCODE_ANTHROPIC_AUTH_LOG_LEVEL` still overrides it. (#543)

## Sidebar

- The Claude sidebar now matches the other CortexKit auth plugins: no frame border, a status dot at the end of each collapsed account row, and the plugin version always on the right of the header.

## Other

- `@cortexkit/common-auth` moves to 0.29.0, which fixes lock release and long paths on Windows.

To upgrade, quit OpenCode and Pi and run `npx @cortexkit/opencode-anthropic-auth setup`, or change the version in your OpenCode config.
