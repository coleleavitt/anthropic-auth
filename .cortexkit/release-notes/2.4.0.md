## OpenCode 2 fixes

- **Request dumps work.** Turning dumps on from `/claude` now writes request and response files on OpenCode 2, as on OpenCode 1. If you already had dumps turned on, OpenCode 2 starts writing them after this update. (#503)
- **Idle sessions stay warm longer.** OpenCode 2 shuts down a folder's copy of the plugin about an hour after its last activity, and cache keep-warm used to forget that folder's sessions at that point. Sessions are now shared by every OpenCode 2 folder using the same accounts, and survive the plugin being shut down or reloaded until their cache would expire. If nothing opens that folder again and no other folder is open, OpenCode doesn't restart the plugin, so those sessions stop being warmed. A server restart still clears them. (#504)

## Setup

- **`setup --help`.** `npx @cortexkit/opencode-anthropic-auth setup --help` lists every setup option. `--host pi` now works as well as `--host=pi`.

## Preparing to move the plugin's files

- **Each process records which account files it uses.** OpenCode 2 reloads its configuration whenever a file in its config folder changes, and the plugin keeps its account state there today. A later release moves the plugin's machine-written files to the CortexKit state folder, and needs to know that no older plugin is still using the old files. From this release, every OpenCode, Pi and setup process writes a small record next to the account files it uses. Nothing moves yet, and your settings files stay where they are.
