## Fixes

- **OpenCode 2 sidebar stays filled.** An account whose quota window has no reset time, for example one with no usage yet in the current five-hour window, blanked the whole Claude sidebar to "Waiting for quota…". The sidebar now shows every account, without a reset time for that window. (#556)
- **Cache keep-warm stops for a blocked account.** When the account a session was last served on is blocked by its own policy, such as a killswitch floor, keep-warm now logs the reason once and stops warming that session. Before, it retried as a network failure until the cache expired. This applies to OpenCode 1, OpenCode 2 and Pi. (#553)

## Improvements

- **Opus 4.8 stand-in keeps the original model's cache (OpenCode 1).** After a refusal, Opus 4.8 serves the next replies and then hands back to the original model. Keep-warm now also keeps the original model's prompt cache alive during that stretch, warming it only shortly before it would expire, so returning to it doesn't rebuild the whole prompt. A restart during a stretch drops this.

To upgrade, quit OpenCode and Pi and run `npx @cortexkit/opencode-anthropic-auth setup`, or change the version in your OpenCode config.
