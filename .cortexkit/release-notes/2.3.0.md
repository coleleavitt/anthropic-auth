## OpenCode 2 fixes

- **The Claude sidebar works again.** Every sidebar refresh failed with a 400, because the plugin's answer contained values OpenCode 2 can't encode. It now loads and stays current. (#475)
- **Quieter in the background.** The sidebar no longer re-reads its preferences file ten times a second per terminal; it checks whether the file changed and reads it only then. A sidebar refresh that fails now backs off, up to 30 seconds, instead of retrying at full speed. (#479)
- **Prime fires.** Prime failed on every check on OpenCode 2 because of a format mismatch in the account fingerprint. It now starts each 5-hour window as designed, and its failure log says which step failed. (#480)
- **A readable `/claude` menu.** The menu opens with section names only, and "View status" shows status in a wide view instead of raw Markdown. (#478)
- **Sessions wait for a short quota reset.** In sticky-balanced mode, a session now stays on its account when whichever quota window blocks it resets within 15 minutes, instead of moving to another account and rebuilding its prompt cache. OpenCode 1 and Pi already worked this way.

## All hosts

- **The plugin logs which vault enrollment it uses.** Once per process, the log names the enrollment file, whether its path came from the environment, the proposed and approved names, and the mode. (#476)
- **Fewer file reads and writes.** `@cortexkit/common-auth` moves to 0.27.1. Settings and enrollment files are read far less often per request, local quota saves are batched, and vault connections give up after 10 seconds.

To upgrade, quit OpenCode and Pi and run `npx @cortexkit/opencode-anthropic-auth setup`, or change the version in your OpenCode config.
