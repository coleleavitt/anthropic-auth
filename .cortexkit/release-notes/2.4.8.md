## Changes

- **One sidebar layout across the CortexKit auth plugins.** The Claude sidebar now uses the same layout as the OpenAI and Antigravity plugins. What you'll notice:
  - A usage window with no reading yet is left out instead of showing `7d —`.
  - The credit line (spent against the monthly limit) now sits below the "checked … ago" line.
  - On narrow sidebars the bar shrinks before the reset time is dropped.
  - After a window resets and before the next reading, the row says "reset since last check".
  - In the collapsed view, idle accounts are drawn in the muted colour and account names use the normal text colour.

  The Routing, Cache and Health sections, the fast-mode row and the refusal-recovery row are unchanged.

## Fixes

- **No repeated quota checks on a refused account in vault mode.** When insula could not refresh an account's quota because Anthropic refused the request, the plugin polled Anthropic itself, which only extended the refusal. It now keeps the last reading and waits. (`@cortexkit/common-auth` 0.32.1)

To upgrade, quit OpenCode and Pi and run `npx @cortexkit/opencode-anthropic-auth setup`, or change the version in your OpenCode config.
