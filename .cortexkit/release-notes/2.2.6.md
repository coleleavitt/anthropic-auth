## What's fixed

- **Local mode no longer drops quota and last-used updates under load.** With several Claude requests running at once in one OpenCode process, as with parallel subagents, each request saved its quota reading and last-used time while holding three nested file locks. Some saves waited 15 seconds, timed out and were lost, so the quota sidebar fell behind and the log filled with `LockContentionError` warnings. Each save now takes only the lock it needs, and saves for the same account are combined. On OpenCode 2, the next request uses the newest quota reading straight away instead of waiting for it to be saved. Vault mode was fixed the same way in 2.2.2. (#461)

To upgrade, quit OpenCode and Pi and run `npx @cortexkit/opencode-anthropic-auth setup`, or change the version in your OpenCode config.
