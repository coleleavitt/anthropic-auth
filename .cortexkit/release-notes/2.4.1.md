## Fixes

- **No more lost turns from a restored effort marker.** On OpenCode, when you change reasoning effort mid-conversation on Opus 5.5, Sonnet 5.5 or Fable 5.1, the plugin attaches a small signed marker and checks it before sending. If another plugin, such as Magic Context, puts back an earlier marker during a tool loop, the plugin refused the request with "Mismatched … effort anchor token" and the turn ended. It now accepts the earlier marker only when it can prove both give exactly the same efforts, and logs a warning. Anything else is still refused. Error messages about effort markers no longer name Fable 5.1 on Opus 5.5 and Sonnet 5.5 requests.
- **Clearer sidebar for a used-up window.** A quota window that is already used up now reads `used up · resets in 2h10m`, instead of `out in now`.

## Compatibility

- **OpenCode 2.2.0.** The plugin now depends on OpenTUI 0.7.0, the version OpenCode 2.2.0's plugin SDK requires, so one copy of OpenTUI installs next to it. OpenCode 1 keeps working, because its sidebar and dialogs run on the OpenTUI that OpenCode ships. (#511)

To upgrade, quit OpenCode and Pi and run `npx @cortexkit/opencode-anthropic-auth setup`, or change the version in your OpenCode config.
