## Fixes

- **OpenCode 2 shows vault accounts right after setup.** `/claude` → Status used to read only the saved account list, which OpenCode 2 fills on the first request through the plugin's own Anthropic connection, so a freshly connected vault looked empty. Status now asks the vault itself, waiting at most two seconds. An empty vault says so, and says how to add an account, instead of "No native Claude accounts." (#528)

## Other

- Dependency updates, including `@cortexkit/claustrum-client` 0.13.0.
- Groundwork for moving the plugin's files out of OpenCode's config folder in a later release. It is switched off, so nothing moves and nothing changes for you.

To upgrade, quit OpenCode and Pi and run `npx @cortexkit/opencode-anthropic-auth setup`, or change the version in your OpenCode config.
