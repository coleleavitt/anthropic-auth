## Fixes

- **No extra quota checks on a capped account.** After a 429 whose own rate-limit headers already show the limit used up, the plugin no longer asks Anthropic's usage endpoint about that account again. Anthropic rate-limits that endpoint per account, and the extra request kept a capped account's quota readings refused for longer. This applies to OpenCode 1 and Pi.

## Improvements

- **Shared routing under the CortexKit agent runner.** When OpenCode runs under CortexKit's agent runner, the plugin asks the shared routing service which Claude account to use and reports quota back. The answer is advisory: the plugin's own account rules (killswitch floors, sign-in state, the Fable reserve, vault custody) still apply, and it falls back to its own choice if routing doesn't answer within 2 seconds. Without the runner, nothing changes.

To upgrade, quit OpenCode and Pi and run `npx @cortexkit/opencode-anthropic-auth setup`, or change the version in your OpenCode config.
