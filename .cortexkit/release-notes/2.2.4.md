## What's fixed

- **A later OpenCode login is imported on setup.** If your first OpenCode 1 setup found no Anthropic account, signing in to Anthropic in OpenCode afterwards and rerunning setup left that login unused, so requests refused until `setup --login`. Setup now imports it while the pool still has no accounts. The login moves into the pool before OpenCode's slot gets the placeholder. Pools that already have accounts are left as they were, and vault-connected hosts are untouched. (#335)
- **Old Claustrum vaults say how to upgrade.** `/claude` → Accounts and setup now say the vault is too old to connect plugins and point to `ck upgrade` for Claustrum v0.2.0 or newer. The vault setup docs name that minimum.

## Under the hood

- CI runs the unit suites and end-to-end tests in parallel, in about 4 minutes instead of 14, with the same checks.

To upgrade, quit OpenCode and Pi and run `npx @cortexkit/opencode-anthropic-auth setup`, or change the version in your OpenCode config.
